# Documentation Index

This directory contains the durable research record.

## Directories

- `handoffs/` — session handouts and research handoff documents.
- `methodology/` — protocols, methodological attacks, measurement definitions, and analysis plans.
- `novelty/` — literature collision analysis and novelty-gap records.
- `preregistration/` — frozen preregistration materials and amendments.
- `literature/` — source registry and literature review records.
